# Bộ sơ đồ PlantUML cho báo cáo

Mỗi tệp `.puml` tương ứng với số hình được ghi trong tên tệp và trong thuộc tính `title`.

- Hình 1.1: mô hình tổng quan người mua, nền tảng, người bán và quản trị viên.
- Hình 1.2: mindmap phạm vi chức năng.
- Hình 3.1: kiến trúc React, NestJS, PostgreSQL và dịch vụ ngoài.
- Hình 3.2: Use Case tổng quát.
- Hình 3.3: Use Case đăng và duyệt tin.
- Hình 3.4: ERD tổng thể.
- Hình 3.5: Activity tạo, thanh toán và duyệt tin.
- Hình 3.6: Sequence chat thời gian thực.
- Hình 3.7: sitemap màn hình.
- Hình D.1: ERD người dùng và xác minh.
- Hình D.2: ERD tin đăng, tương tác và thanh toán.
- Hình E.1: Sequence đăng ký, OTP và 2FA.
- Hình E.2: Activity AI và thanh toán.
- Hình E.3: kiểm duyệt tin và xử lý báo cáo.
- Hình G.1: pipeline CI/CD.

Dán nội dung từng tệp vào PlantText, PlantUML Server hoặc extension PlantUML trong Visual Studio Code, sau đó xuất PNG hoặc SVG.

Hình 4.1–4.21, Hình 5.1–5.2 và Hình A.1 là ảnh chụp giao diện hoặc kết quả thực tế. Biểu đồ G.1 cần số liệu kiểm thử tải thực tế. Các Bảng 1.1, 5.1, B.1, D.1, F.1, F.2 và G.1 nên tạo bằng bảng Word.
